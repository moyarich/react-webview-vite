# Getting Started

## Requirements

- Node.js 22 or newer
- npm
- VS Code `^1.118.0`

## Install dependencies

```bash
npm ci
```

## Build

```bash
npm run build
```

The build emits the extension bundle to `out/` and browser webview assets to `out/webview-ui/`.

## Run the extension

Open the repository in VS Code and press `F5` to launch an Extension Development Host.

Available commands include:

```text
Dependency Links: Open Inspector
Dependency Links: Open Dependency Graph
```

## Browser preview workspace

Run:

```bash
npm run dev
```

This starts Vite and opens the clean preview route:

```text
/previews/dependency-explorer
```

Use the preview sidebar to switch between the Inspector and Dependency Explorer without restarting Vite.

## Watch extension builds

Run both extension and webview build targets in watch mode:

```bash
npm run watch
```

The extension host and webview bundles rebuild independently while developing.
