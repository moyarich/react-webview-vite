# Development Workflow

## Common commands

| Command | Purpose |
| --- | --- |
| `npm run build` | Clean and build the extension and webviews |
| `npm run watch` | Watch extension and webview bundles |
| `npm run dev` | Run the browser preview workspace |
| `npm run dev:inspector` | Open the Inspector preview route |
| `npm run dev:explorer` | Open the Dependency Explorer preview route |
| `npm run dev:extension` | Launch the VS Code extension development environment |
| `npm run typecheck` | Type-check extension, webviews, and preview shell |
| `npm run lint` | Lint source and preview React code |
| `npm run test:unit` | Run Vitest unit tests |
| `npm test` | Run unit and VS Code integration tests |
| `npm run deps:check` | Validate dependency boundaries |

## Browser previews

```bash
npm run dev
```

The React Router preview shell uses clean routes:

```text
/previews/inspector
/previews/dependency-explorer
```

Vite rewrites those known development routes to `previews/index.html`, so direct navigation and browser refreshes work with `BrowserRouter`.

The actual iframe entry pages remain separate:

```text
/previews/inspector.html
/previews/dependency-graph.html
```

That separation keeps the preview shell responsible for navigation while the iframe pages continue to load the same webview entry modules used during webview development.

## Dependency utility changes

Keep browser-safe parsing, dependency analysis, filtering, and version helpers under:

```text
src/utils/
```

Do not route browser-safe package parsing through the extension host.

## Webview changes

React webviews live under:

```text
src/webview-ui/
```

The extension host owns VS Code APIs, workspace file access, source navigation, manifest discovery, and package-lock inspection. Webviews communicate with it through contracts in `src/shared/messages.ts`.

## Preview shell changes

The development preview app lives under:

```text
previews/
├── index.html
└── src/
    ├── App.tsx
    ├── main.tsx
    └── preview.css
```

Keep preview-only UI and routing out of `src/webview-ui/`. The preview shell is development tooling, not extension runtime code.

## Dependency architecture checks

Run:

```bash
npm run deps:check
```

Generate a Mermaid dependency diagram with:

```bash
npm run deps:graph
```
