## Project layout

```text
.
├── src/
│   ├── dependencies.ts
│   ├── extension.ts
│   ├── shared/
│   ├── test/
│   └── webview/
├── docs/
├── vite.extension.config.ts
├── vite.webview.config.ts
├── tsconfig.json
└── tsconfig.webview.json
```

The VS Code extension host and React webview are separate build targets. Shared message contracts and types live under `src/shared/`.
